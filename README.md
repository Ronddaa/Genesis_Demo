# Перевірка рекламних банерів: інструкція

Інструмент перевіряє, чи збігаються банери з брифом: мова, відсоток знижки і промокод.

## Як користуватися

### 1. Заповніть бриф

У блоці Brief вкажіть, що має бути на банерах. **Потрібне хоча б одне поле.**

| Поле | Що вводити | Приклад |
|---|---|---|
| Check Language | Мова, яка має бути на банері (одна) | `it` або `italian` |
| Exact discount (%) | Точна знижка, ціле число від 1 до 100 | `20` |
| Promo Code | Промокод так, як він написаний на банері | `LAVANDA` |

### 2. Додайте банери

Перетягніть файли у велику область або натисніть **browse files**. Можна вибрати
одразу кілька.

- Формат: **PNG або JPEG**, до **5 МБ** кожен.
- Однакові файли додаються один раз, дублікати пропускаються.
- Щоб прибрати банер зі списку, наведіть на нього курсор і натисніть на кошик.

### 3. Запустіть перевірку

Натисніть **Check banners**. Банери перевіряються по кілька одночасно, результат
з'являється на кожному, щойно він готовий.

## Як читати результат

У блоці **Results** видно підсумок: скільки оброблено, скільки пройшло, скільки з
помилками, скільки потребує перегляду.

| Статус | Колір на банері | Що робити |
|---|---|---|
| `PASS` | Банер прихований зі списку | Нічого, усе збігається з брифом |
| `FAIL` | Червоний | Є розбіжність, виправте банер |
| `REVIEW` | Помаранчевий | Система не впевнена, подивіться банер самі |
| Processing error | Текст помилки | Натисніть **Retry** на цьому банері |

- Для кожної проблеми показано **Expected** (що вимагав бриф) і **Observed** (що знайдено
  на банері), а також фрагмент тексту, на якому це видно.
- Щоб побачити банер без червоного або помаранчевого шару, наведіть на нього курсор.
- Пройдені банери за замовчуванням сховані. Щоб їх повернути, натисніть
  **Show passed banners**.

## Корисно знати

- Якщо в брифі точна знижка `20`, а на банері написано «до 20%» або «від 20%», це
  буде розбіжність.
- Промокод порівнюється точно, тож `Lavanda` і `LAVANDA` не збігаються.
- Якщо текст на банері дрібний, розмитий або частково закритий, результат буде `REVIEW`,
  а не припущення. Це нормально.
- Якщо бриф порожній, система попросить заповнити хоча б одне поле.

## Типові помилки

| Повідомлення | Причина |
|---|---|
| The file exceeds 5 MiB | Файл завеликий, стисніть його |
| Select a PNG or JPEG image | Непідтримуваний формат |
| The file is empty | Файл порожній або пошкоджений |
| Set at least one requirement in the campaign brief | Не заповнено жодного поля брифу |
| The discount must be a whole number from 1 to 100 | Знижку треба вказати цілим числом, без `%` |
